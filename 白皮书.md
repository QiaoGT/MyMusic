# MyMusic 项目白皮书

## 1. 项目概述
**MyMusic** 是一个基于 Web 的个人原创音乐播放平台。它不依赖传统的音乐云服务，而是通过解析 GitHub 仓库中的媒体文件，实现音乐在线播放、歌词同步滚动及动态封面展示。

*   **项目名称：** MyMusic
*   **存储中心：** GitHub (仓库名: `MyMusic`)
*   **部署平台：** Vercel
*   **核心特性：** 自动化列表获取、文件同名关联解析、响应式设计、极简视觉体验。

---

## 2. 技术架构与数据逻辑

### 2.1 存储结构
仓库中音乐、歌词、封面将严格按照以下目录结构存放，且文件名必须保持一致：
```text
MyMusic (Root)
├── muc/   <-- 存放音乐文件 (例如: 1.mp3, 2.mp3)
├── lrc/   <-- 存放歌词文件 (例如: 1.lrc, 2.lrc)
├── img/   <-- 存放封面图片 (例如: 1.jpg, 2.png)
└── index.html / script.js / style.css <-- 播放器前端代码
```

### 2.2 数据获取逻辑
1.  **动态扫描：** 播放器启动时，通过 **GitHub REST API** 请求 `muc` 文件夹下的文件列表。
2.  **链接转换：** 将 API 返回的文件名映射为 `raw.githubusercontent.com` 的原始链接格式。
3.  **资源关联：** 根据音乐文件名（如 `SongA.mp3`），自动推导并请求 `lrc/SongA.lrc` 和 `img/SongA.jpg`。

---

## 3. 功能特性清单
*   **自动发现：** 只需将新歌上传到 GitHub，播放器刷新后自动同步，无需修改代码。
*   **智能关联：** 自动匹配同名歌词与封面。
*   **歌词同步：** 支持标准 LRC 时间轴解析。
*   **实时日期：** 界面集成动态日期与时间显示。
*   **Vercel 优化：** 针对单页应用（SPA）优化，支持快速分发。

### 4.2 script.js (核心逻辑)
**注意：** 请将代码中的 `USER_NAME` 和 `REPO_NAME` 替换为你自己的。

```javascript
const CONFIG = {
    user: 'wiobr21',
    repo: 'resources', // 如果你的仓库叫MyMusic，请改为MyMusic
    branch: 'main',
    musicFolder: 'mus',
    lrcFolder: 'lrc',
    imgFolder: 'img'
};

const rawBase = `https://raw.githubusercontent.com/${CONFIG.user}/${CONFIG.repo}/${CONFIG.branch}`;
const apiBase = `https://api.github.com/repos/${CONFIG.user}/${CONFIG.repo}/contents/${CONFIG.musicFolder}`;

let playlist = [];
let currentIndex = 0;
let lrcLines = [];

const audio = document.getElementById('audio-element');

// 1. 从GitHub获取文件列表
async function fetchPlaylist() {
    try {
        const response = await fetch(apiBase);
        const files = await response.json();
        
        playlist = files
            .filter(file => file.name.endsWith('.mp3'))
            .map(file => {
                const baseName = file.name.replace('.mp3', '');
                return {
                    name: baseName,
                    url: `${rawBase}/${CONFIG.musicFolder}/${encodeURIComponent(file.name)}`,
                    lrc: `${rawBase}/${CONFIG.lrcFolder}/${encodeURIComponent(baseName)}.lrc`,
                    img: `${rawBase}/${CONFIG.imgFolder}/${encodeURIComponent(baseName)}.jpg`
                };
            });
        
        renderPlaylist();
        if(playlist.length > 0) loadSong(0);
    } catch (err) {
        console.error("获取列表失败:", err);
    }
}

// 2. 渲染列表
function renderPlaylist() {
    const listEl = document.getElementById('music-list');
    listEl.innerHTML = playlist.map((song, i) => `
        <li onclick="loadSong(${i})" class="${i === currentIndex ? 'active' : ''}">
            ${song.name}
        </li>
    `).join('');
}

// 3. 加载歌曲
async function loadSong(index) {
    currentIndex = index;
    const song = playlist[index];
    
    audio.src = song.url;
    document.getElementById('current-title').innerText = song.name;
    document.getElementById('current-cover').src = song.img;
    document.querySelector('.background-blur').style.backgroundImage = `url(${song.img})`;

    // 获取并解析歌词
    fetchLyrics(song.lrc);
    renderPlaylist();
    audio.play();
}

// 4. 解析歌词 (LRC)
async function fetchLyrics(url) {
    const wrap = document.getElementById('lyric-wrapper');
    wrap.innerHTML = '<p>加载歌词中...</p>';
    try {
        const res = await fetch(url);
        const text = await res.text();
        lrcLines = text.split('\n').map(line => {
            const match = line.match(/\[(\d+):(\d+\.\d+)\](.*)/);
            if(match) return { time: parseInt(match[1])*60 + parseFloat(match[2]), text: match[3] };
        }).filter(v => v);
        
        wrap.innerHTML = lrcLines.map(l => `<p>${l.text}</p>`).join('');
    } catch {
        wrap.innerHTML = '<p>暂无歌词</p>';
    }
}

// 5. 歌词同步滚动
audio.ontimeupdate = () => {
    const cur = audio.currentTime;
    const idx = lrcLines.findIndex((l, i) => cur >= l.time && (!lrcLines[i+1] || cur < lrcLines[i+1].time));
    if(idx !== -1) {
        const p = document.querySelectorAll('#lyric-wrapper p');
        p.forEach(el => el.classList.remove('active'));
        if(p[idx]) {
            p[idx].classList.add('active');
            document.getElementById('lyric-wrapper').style.transform = `translateY(${-idx * 40 + 150}px)`;
        }
    }
    document.getElementById('progress-bar').value = (audio.currentTime / audio.duration) * 100 || 0;
};

// 6. 时间显示
function updateClock() {
    const now = new Date();
    document.getElementById('clock-time').innerText = now.toLocaleTimeString([], {hour: '2-digit', minute:'2-digit'});
    document.getElementById('clock-date').innerText = now.toLocaleDateString('zh-CN', {year:'numeric', month:'long', day:'numeric'});
}

setInterval(updateClock, 1000);
fetchPlaylist();

// 控制按钮
document.getElementById('btn-play').onclick = () => audio.paused ? audio.play() : audio.pause();
document.getElementById('btn-next').onclick = () => loadSong((currentIndex + 1) % playlist.length);
document.getElementById('btn-prev').onclick = () => loadSong((currentIndex - 1 + playlist.length) % playlist.length);
```

## 5. 部署指南 (Vercel)

1.  **准备 GitHub 仓库：** 
    *   将上述 `index.html`, `script.js`, `style.css` 放在仓库根目录。
    *   建立 `mus`, `lrc`, `img` 文件夹，并上传你的音乐作品。
2.  **连接 Vercel：**
    *   登录 [Vercel官网](https://vercel.com/)。
    *   点击 "Add New" -> "Project"。
    *   导入你的 `MyMusic` 仓库。
3.  **环境变量 (可选)：**
    *   如果你希望提高 GitHub API 的调用频率限制，可以在 Vercel 后台设置环境变量 `GITHUB_TOKEN`，但对于个人低频访问，不设置也可以。
4.  **部署：**
    *   点击 "Deploy"。完成后，你将获得一个 `xxx.vercel.app` 的链接。
